# Bank Loan Analysis

## Project Overview
This project focuses on analyzing bank loan data to understand loan applications, funding, repayments, borrower details, and loan performance.

## Tools & Technologies
- MySQL – Data cleaning and SQL analysis
- Power BI – Interactive dashboard development
- Microsoft Excel – Source data

## Project Objectives
- Analyze total loan applications and funded amounts.
- Understand loan performance and repayment trends.
- Compare verified and non-verified borrower payments.
- Analyze loan distribution by grade, state, and home ownership.
- Present key insights through an interactive dashboard.

## Project Components
1. Data Cleaning using MySQL
2. SQL Analysis
3. Power BI Dashboard
4. Project Documentation
