# Bank Loan Analysis

### A Data Analytics Project Using MySQL and Power BI

## Project Overview

This project focuses on analyzing bank loan data to understand loan applications, funded amounts, repayments, borrower characteristics, and loan performance.

The project uses MySQL for data cleaning and SQL analysis, and Power BI to develop an interactive dashboard that presents key financial metrics and trends.

## Project Objectives

- Analyze loan application and funding trends.
- Understand loan repayment patterns.
- Compare verified and non-verified borrower payments.
- Examine loan distribution across grades and states.
- Analyze loan status and home ownership patterns.
- Present insights through interactive visualizations.

## Tools & Technologies

| Tool | Purpose |
|---|---|
| MySQL | Data cleaning and SQL analysis |
| Power BI | Interactive dashboard development |
| Microsoft Excel | Source data |

## Project Workflow

1. Data Import – Imported the two finance datasets.
2. Data Cleaning – Prepared working copies and performed data cleaning using MySQL.
3. SQL Analysis – Developed SQL queries to explore loan and payment information.
4. Dashboard Development – Created an interactive Power BI dashboard.
5. Documentation – Prepared project documentation and supporting files.

## Dashboard Highlights

The Power BI dashboard includes:

- Total Loan Amount
- Total Funded Amount
- Total Payments
- Average Loan Amount
- Average Interest Rate
- Year-wise loan statistics
- Grade-wise revolving balance
- Verified vs Non-Verified payments
- State-wise and month-wise loan status
- Home ownership vs last payment date
